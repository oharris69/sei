# accordion

Custom **accordion** block. 

## Authoring (Document Authoring)

Model: `standalone`

Single block table, one row per item, two cells per row:

| Accordion |  |
| --- | --- |
| View transcript | Body text (paragraphs, **bold** lead-ins, lists, links) |
| More on our values | ... |

- Every item starts closed. It opens with a click, or with Enter/Space from the keyboard (native `<details>`/`<summary>`).
- Rows with an empty label are dropped. A row with no body cell still renders, with an empty body.

## Supported variations

No variations.
